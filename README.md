# TRex Mod

Add realistic T-Rex dinosaurs to your Minecraft world

## Features

- Adds a realistic T-Rex entity to Minecraft
- Custom models and animations for the T-Rex
- Configurable spawn rates and biome variations
- Custom sounds and behaviors for the T-Rex

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.11 or later
- Fabric API 0.96.11 or later

## Installation

1. Download the latest version of the mod from the [releases page](https://github.com/EnderDevelopment/trex-mod/releases).
2. Place the downloaded JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

Once installed, the T-Rex entity will spawn naturally in the configured biomes. You can also spawn a T-Rex using a spawn egg, which can be obtained by crafting or finding one in the game.

## Configuration

The mod includes a configuration file that allows you to customize various aspects of the T-Rex entity, such as spawn rates, biome variations, and more. The configuration file is located in the `config` folder of your Minecraft instance.
